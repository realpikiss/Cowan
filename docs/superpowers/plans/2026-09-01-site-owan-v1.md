# Site OWAN INTER LINK v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v1 OWAN INTER LINK website as a static, framework-free HTML/CSS/JS site (11 pages) matching the approved design spec.

**Architecture:** Multi-page static site. One shared stylesheet (`css/style.css`) and one shared script (`js/main.js`) are included by every page. Header and footer markup is identical across pages (no template/include mechanism exists in plain HTML, so the exact same markup is reproduced on every page). Forms and CTA buttons never talk to a server — JavaScript builds a WhatsApp deep link (`https://wa.me/...`) from form field values and redirects the browser there.

**Tech Stack:** HTML5, CSS3 (custom properties, flexbox, grid, media queries), vanilla JavaScript (no libraries, no build step, no package manager).

## Global Constraints

- HTML/CSS/JS pur uniquement — aucun framework (React, Bootstrap, etc.), aucun build step, aucun `package.json`/`node_modules`.
- Site en français uniquement pour cette v1 — pas de bascule de langue à construire.
- Aucun backend : les deux formulaires (`whatsapp-form`) redirigent vers `https://wa.me/<WHATSAPP_NUMBER>?text=...` ; aucune requête réseau n'est envoyée à un serveur applicatif.
- Aucun upload réel de fichier — le champ photo/lien du formulaire d'accueil est une note textuelle expliquant que la photo se joint directement dans WhatsApp.
- Toutes les coordonnées réelles (numéro WhatsApp, téléphone, email, adresse, horaires, réseaux sociaux) sont inconnues pour l'instant : elles sont soit une constante unique `WHATSAPP_NUMBER` en haut de `js/main.js`, soit un texte entre crochets clairement identifiable dans le HTML (ex. `[TÉLÉPHONE OWAN]`), pour qu'une seule recherche/remplacement suffise plus tard.
- Mobile-first, style sobre : peu d'animations, pas de vidéo, pas de police externe (police système uniquement).
- Pas de suite de tests automatisée classique (pas de npm/jest/pytest — cela violerait la contrainte "zéro build step"). La logique JS pure (`js/main.js`) est vérifiée avec un harnais de test HTML autonome (`js/main.test.html`, sans dépendance) ouvert dans un navigateur. Le rendu des pages HTML/CSS est vérifié manuellement dans un navigateur (checklist fournie dans chaque tâche) et par un script bash de vérification des liens internes cassés (dernière tâche).
- Chaque page a `<html lang="fr">`, une balise `<meta name="viewport" content="width=device-width, initial-scale=1">`, un `<title>` et une `<meta name="description">` propres à la page (SEO de base).

- [ ] **Step 3: Write `js/main.js`**

```js
const WHATSAPP_NUMBER = "225XXXXXXXXX";

function initMobileNav() {
  const toggle = document.getElementById("navToggle");
  const menu = document.getElementById("navMenu");
  if (!toggle || !menu) return;
  toggle.addEventListener("click", () => {
    const isOpen = menu.classList.toggle("is-open");
    toggle.setAttribute("aria-expanded", String(isOpen));
  });
}

function buildWhatsAppMessage(form) {
  const intro = form.dataset.intro || "Bonjour OWAN,";
  const lines = [intro];
  const fields = form.querySelectorAll("input[name], select[name], textarea[name]");
  fields.forEach((field) => {
    const value = field.value.trim();
    if (!value) return;
    const label = form.querySelector(`label[for="${field.id}"]`);
    const labelText = label ? label.textContent.trim() : field.name;
    lines.push(`${labelText} : ${value}`);
  });
  return lines.join("\n");
}

function whatsAppUrl(message) {
  return `https://wa.me/${WHATSAPP_NUMBER}?text=${encodeURIComponent(message)}`;
}

function initWhatsAppForms() {
  document.querySelectorAll("form.whatsapp-form").forEach((form) => {
    form.addEventListener("submit", (event) => {
      event.preventDefault();
      const message = buildWhatsAppMessage(form);
      window.location.href = whatsAppUrl(message);
    });
  });
}

function initWhatsAppLinks() {
  document.querySelectorAll("a.whatsapp-link").forEach((link) => {
    const message = link.dataset.message || "Bonjour OWAN,";
    link.href = whatsAppUrl(message);
    link.target = "_blank";
    link.rel = "noopener";
  });
}

document.addEventListener("DOMContentLoaded", () => {
  initMobileNav();
  initWhatsAppForms();
  initWhatsAppLinks();
});
```
